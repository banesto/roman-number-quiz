# Roman Rocket

A kid-friendly Roman numeral learning game built with plain HTML, CSS, and JavaScript. Players identify a Roman numeral from four possible answers across a 10-question round, with scoring that rewards accuracy first and speed second.

## Play online

**[Launch Roman Rocket](https://banesto.github.io/roman-number-quiz/)**

> The link will become available after GitHub Pages is enabled for the repository.

## Features

- Four learning ranges: 1–8, 1–10, 1–100, and 1–1000
- Ten randomized questions per round
- Accuracy-focused scoring with a small speed bonus
- Visible timer, progress indicator, and results screen
- Clickable answers and direct keyboard input
- Roman numeral reference legend from I to M
- Responsive layout for desktop and mobile
- No dependencies or build step

## Run locally

Open `index.html` in a web browser.

## Publish with GitHub Pages

In the GitHub repository, open **Settings → Pages**, select **Deploy from a branch**, choose the `master` branch and the `/ (root)` folder, then save.
